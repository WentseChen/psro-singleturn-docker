## 1. 为什么要升级

v5 上，s8889 的 stream fork 在训练 A4 时两次崩溃，报错依次是：

```
Prompt length of 14500 is longer than the maximum model length of 8192
Output count mismatch: expected 32, got 60
```

原因：WildGuard judge 没有检查输入长度。一条超长的「攻击 + 回复」会让整批打分失败（HTTP 500），
并在 judge 里留下残留请求，之后每一批都返回错误数量的结果；训练端重试 12 次后退出。

v6 只修改了 judge 服务端：每一步的文本最多保留 2048 个 WildGuard token（正常文本不受影响），
打分失败时清空残留请求。**训练代码、reward、所有参数与 v5 完全相同。**
已在真实 WildGuard（H200）上验证：旧代码能复现上面两个报错；v6 下三批请求全部成功，正常样本的打分与旧代码完全一致。
